# Checkr

Автоматична валідація товарного фіду e-commerce.

Програма зчитує файл (CSV або Excel) зі списком товарів і знаходить логічні розбіжності між назвою, описами та характеристиками одного й того ж товару (наприклад, конфлікт об'єму SSD або RAM).

## Функціонал

- **Нативний графічний інтерфейс** — зручна робота без браузера
- **Веб-інтерфейс (Web-GUI)** — опціональне завантаження файлу через браузер
- Читає **CSV** (авто-визначення роздільника) та **Excel** (`.xlsx`, `.xls`)
- Очищає текстові поля від **HTML-тегів** перед аналізом
- **Перевірка мов** — виявляє невідповідність російської та української версій тексту
- Знаходить значення пам'яті (`512ГБ`, `512 GB`, `1ТБ`, `32GB` тощо) за **regex** в усіх текстових полях
- Перевіряє **діагональ екрана**, **вагу**, **роздільну здатність**, **тип матриці** та інші характеристики
- Порівнює знайдені значення з еталонними у колонках характеристик
- Записує детальне пояснення у нову колонку **«Помилки»**
- Зберігає вихідний `.xlsx` з **кольоровим підсвіченням**: 🟥 червоний — конфліктні поля, 🟨 жовтий — опис помилки
- Виводить **координати** всіх конфліктних клітинок у консоль (або GUI)
- **Автоматично зберігає результат** і дозволяє завантажити його (при використанні GUI)

## Встановлення

```bash
pip install -r requirements.txt
```

**Примітка:** Для використання нативного GUI (`checkr_native_gui.py`) потрібен **tkinter**, який зазвичай встановлений за замовчуванням у Python. Якщо tkinter відсутній:
- **Windows/macOS:** tkinter входить до складу стандартної установки Python
- **Linux (Debian/Ubuntu):** `sudo apt-get install python3-tk`
- **Linux (Fedora):** `sudo dnf install python3-tkinter`

Якщо tkinter недоступний, використовуйте веб-інтерфейс (`checkr_gui.py`) або CLI (`checkr.py`).

## Використання

### Графічний інтерфейс (Native GUI) — **РЕКОМЕНДОВАНО**

```bash
python checkr_native_gui.py
```

Відкриється нативне вікно програми (без браузера):
1. Натиснути **"Вибрати файл"** та обрати CSV/Excel файл
2. Натиснути **"Перевірити файл"**
3. Результат автоматично збережеться у директорії з вихідним файлом з суфіксом `_result.xlsx`
4. Натиснути **"Відкрити файл результату"** для перегляду

**Переваги:**
- Не потребує браузера
- Швидше запускається
- Зручніший у використанні

### Графічний інтерфейс (Web-GUI) — застарілий

```bash
python checkr_gui.py
```

Відкриється локальний веб-сервер. Перейдіть за адресою **http://localhost:5000** у браузері, де можна:
1. Натиснути на область завантаження або перетягнути CSV/Excel файл
2. Натиснути **"Перевірити файл"**
3. Результат автоматично збережеться у системній тимчасовій директорії з суфіксом `_result.xlsx`
4. Завантажити результат через посилання на сторінці

**Обмеження:** Максимальний розмір файлу - 50MB

### Командний рядок (CLI)

```bash
python checkr.py <вхідний_файл> [<вихідний_файл.xlsx>]
```

Якщо вихідний файл не вказано, автоматично створюється файл `<вхідний_файл>_result.xlsx`.

Приклади:
```bash
python checkr.py products.csv result.xlsx      # явне вказання вихідного файлу
python checkr.py products.xlsx result.xlsx     # явне вказання вихідного файлу
python checkr.py sample_data.csv               # створить sample_data_result.xlsx
```

## Структура вхідного файлу

Файл має містити принаймні деякі з таких колонок (заголовки можуть мати ID після `;`):

| Колонка | Призначення |
|---|---|
| `Название` | Назва товару (рос.) |
| `Назва (ua)` | Назва товару (укр.) |
| `Краткое описание` | Короткий опис |
| `Описание;1` | Повний опис (може містити HTML) |
| `Объём SSD;115411` | Характеристика: ємність SSD |
| `Объем установленной оперативной памяти;20863` | Характеристика: об'єм RAM |

## Додавання нових правил перевірки

Відкрийте `checkr.py` та додайте новий блок у список `VALIDATION_RULES`:

```python
VALIDATION_RULES = [
    # Існуючі правила...

    # Нове правило — GPU VRAM
    {
        "label": "GPU VRAM",
        "char_hints": ["Відеопам'ять", "Видеопамять", "VRAM"],
        "text_hints": ["Название", "Назва", "Краткое описание", "Описание"],
    },
]
```
